# Sonora

Client-side Fabric mod: an in-game music player for Spotify and local music files, with a mini player, full player, lyrics, equalizer and visualizer.

## Features

- Spotify playback and browsing, plus a local music library.
- Mini player on screen and a full player screen.
- Synced lyrics, equalizer and visualizer.
- Track toasts and album artwork.
- English and Russian translations.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Client-side only.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
